DevOps Lab Exam
Definitions


DevOps: DevOps is a practice of combining software development and IT operations to automate and integrate the processes between them. The main goal is to shorten the system development lifecycle and provide continuous delivery with high quality.

CI(Continuous Integration): The practice of frequently merging all developers' working copies to a shared mainline, where automated builds and tests are run.

CD(Continuous Delivery/Deployement): Continuous Delivery ensures that the software is release-ready at any time via automated pipelines. 

Containerization: Packaging an application and its entire runtime environment ie libraries, config files, etc into a single isolated container to ensure it runs consistently across different environments. 

Rollback: The process of reverting a deployed system or application to the previous stable version to quickly recover from a bug or failed deployement.
